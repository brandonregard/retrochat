RetroChat for NetBSD 10.1/mac68k
================================

Under X11, open an xterm, become root, and run the installer from the mounted
RetroChat CD:

  su -
  cd /path/to/mounted/retrochat/cd
  sh INSTALL.SH

The installer includes Tcl/Tk and every required m68k binary dependency. It
installs that runtime automatically when needed, without a network connection,
then installs both applications and creates these commands in /usr/local/bin:

  retrochat-client
  retrochat-server 7777

Run the client and graphical server from an xterm after X11 has started. The
server also runs headlessly from a text console. The stock NetBSD 10.1/mac68k
X server is monochrome; RetroChat automatically uses black text on a white
background when the display is one bit deep.
