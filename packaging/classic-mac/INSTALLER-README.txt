RetroChat @VERSION@ for Classic Mac OS
==================================

This release supports 68K and PowerPC Macintosh computers running Mac OS 7,
Mac OS 8, or Mac OS 9. The applications are fat binaries: each contains both
68K code resources and PowerPC executable code.

RetroChat Client connects to a RetroChat server. RetroChat Server listens on
TCP port 7777 by default and provides a small controller window with a Quit
button.

No separate Tcl/Tk installation is required.
